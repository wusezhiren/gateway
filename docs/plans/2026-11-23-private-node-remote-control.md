# 管理员私有节点与外网控制计划

**目标：** 普通成员在局域网和外网都看不到、不能操作 PC 供电插座。管理员在 Android App 输入密码后，可通过 Wi-Fi 或移动数据查看并控制插座。

**范围：** Android App、网关固件和云端 MQTT 配置。现有 ESP8266 插座无需刷机或重新配对。

| 阶段 | 改动位置 | 实施内容 | 验收标准 |
| --- | --- | --- | --- |
| 1. 私有节点 | 网关固件 | 持久化节点的「仅管理员可见」标记；支持已有节点转为私有，以及新节点在首次发布前设为私有。普通设备列表和共享状态过滤私有节点；在 HTTP 和 MQTT 的节点操作入口检查权限。 | 网关重启后设置仍有效；普通成员即使知道节点 MAC，也不能查询、开关、解绑或升级该节点。 |
| 2. 管理员解锁 | 网关固件、Android App | 网关验证密码并签发短时会话，对失败尝试限速。App 解锁后才加载私有列表；支持立即锁定和超时锁定，锁定时清除私有列表缓存。 | 密码正确后才显示插座；锁定后立即隐藏；过期会话无法读取或控制私有节点。 |
| 3. 外网隔离 | 云端 MQTT 配置、网关固件、Android App | 区分网关、普通成员与管理员的 MQTT 凭据，使用主题 ACL 隔离管理员命令和私有响应。网关逐条校验管理员会话；私有响应不设为保留消息。切换时用过滤后的状态覆盖旧共享保留消息，并收紧或撤销旧共享凭据。 | 普通凭据不能订阅私有响应或发布管理员命令；管理员关闭 Wi-Fi 后，能在移动数据下输入密码、查看节点并控制插座。 |
| 4. 防误断电与回归 | Android App、网关固件 | 提供节点私有设置和配对选项；对 PC 插座的关电操作增加二次确认。检查共享自动化或批量操作不会间接控制私有节点；先用非关键负载联调。 | 取消确认不会发送断电命令；远程开机仍可用；普通成员仍可操作其他节点。 |

## 上线与验收

1. 配置 MQTT 权限并升级网关，验证普通节点控制正常；处理旧共享凭据和保留消息。
2. 更新管理员手机的 App，设置管理员密码，用非关键负载验证后，把现有 ESP8266 插座设为私有。
3. 用两台手机验收：管理员手机关闭 Wi-Fi，解锁后查看插座并验证开关流程；普通成员手机分别使用 Wi-Fi 和移动数据，均看不到该插座。用旧版 App 回归确认普通节点仍可操作。
4. 检查普通成员从已知 MAC、共享自动化和旧 MQTT 凭据发起的操作均被拒绝；验证锁定、会话过期、网关重启以及 MQTT 重连后的权限行为。
