# 测试覆盖清单

运行入口：`bash tools/test_host.sh`（共享 ESP-NOW 协议及 TTS 重采样）；`cd android && ./gradlew :app:testDebugUnitTest`（App 单元测试）。固件编译、实机测试不等同于单元测试。

| 模块 | 自动化正向/反向用例 | 尚需覆盖 |
| --- | --- | --- |
| 网关/节点共享 meshproto | 有效/无效 magic、版本、类型、截断帧、旧/新 JOIN 长度、RGB 位域、peer 新增/修改 | 加密密钥错误、ESP-NOW 发送/接收的板上测试 |
| 网关 TTS 24→16 kHz | 正常帧、跨帧剩余样本、双声道值、空指针与零容量 | 音质、真实解码帧和扬声器试听 |
| 网关语音判停 VAD | 低音量语音、静音判停、短噪声不误触发、无语音不判停、回到讲话重置静音、无效输入 | 真实环境噪声/远场讲话及播放回声 |
| 网关打断链路 | 状态机正反向测试；板上标准 TX + 2 槽 RX 同时运行；脚本灌入完整唤醒词和指令，连续两轮取消旧会话、第二轮 STT/MCP 完成，无 I2S 通道错误；灌静音不触发打断 | 真人打断的声学效果与音质仍需现场确认，尤其打断时连说完整指令 |
| 网关 SET 重试策略 | 普通/省电节点间隔及次数、最短窗口、极值防溢出、实际状态相符/不符 | 无线丢包、实际继电器确认、超时重发的板上验证 |
| 节点 OTA 分片/版本策略 | 新旧同版、正常顺序分片、重复/乱序、零长、超长、截断、越界/溢出 | SHA-256、签名、分区切换、掉电回滚实机验证 |
| 网关 OTA 版本策略 | 新版、旧版、同版、缺省修订号及空输入 | 镜像头、SHA-256、分区切换、回滚的失败注入与实机验证 |
| App 固件解析和版本 | 有效镜像、无效 magic/短镜像、版本大小关系 | 内置 asset、OTA 上传和签名发布包 |
| App RGB | 打包/解包、关灯、非法亮度截断 | UI 操作、设备状态同步 |
| 网关 WakeNet / 音频 / WebSocket / MCP | — | 正向：唤醒→STT→工具→TTS，连续/打断；反向：缺 SD/模型、断网、TLS 失败、超时、队列溢出、资源释放、扬声器回声误唤醒 |
| 网关 Wi-Fi / 配网 / HTTP / MQTT / OTA / 节点升级 / UI | — | 正向：连接、鉴权、升级、触摸；反向：断网、错误凭据、非法请求、校验失败、掉电/回滚、内存不足 |
| 节点链路 / IO / OTA / 省电 | — | 正向：配对、SET/ACK、继电器、升级和省电窗口；反向：重复/乱序包、丢包、非法通道、失败重试、镜像错误和回滚 |
| App 发现 / 绑定 / 网络切换 / 云控 / 更新 / 小组件 / 快捷开关 / UI | — | 正向：本地和云端控制、发现及更新；反向：权限拒绝、超时、离线、错误响应、安装失败及状态不同步 |

当前自动化覆盖尚未达到全仓正反向要求；打断的控制链路已接入并通过受控板测，但真实声学打断尚未验收。后续逐模块隔离依赖、增加模拟器和设备集成测试，并在表中登记实际通过结果。
